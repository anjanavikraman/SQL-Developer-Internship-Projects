# SQL Developer Internship Projects

This repository contains the projects completed as part of my SQL Developer Internship.

## Projects

### Project 1: Online Retail Sales Database

A MySQL-based database project designed to manage online retail sales, customers, products, orders, order items, and payments.

**Tools Used:**
- MySQL
- MySQL Workbench
- SQL

**Key Features:**
- Relational database design
- Primary and Foreign Keys
- Customer and product management
- Order and payment management
- SQL JOIN queries
- Sales reports
- Sales report view
- ER diagram

### Project 14: Crime Record & Investigation Database

A PostgreSQL-based database project designed to manage crime cases, suspects, investigating officers, and evidence.

**Tools Used:**
- PostgreSQL
- pgAdmin
- SQL
- PL/pgSQL

**Key Features:**
- Relational database design
- Primary and Foreign Keys
- Indexing
- Case status analysis
- Officer workload view
- Evidence chain of custody trigger
- Investigation summary reports
- Stored function for case details
- ER diagram

## Technologies

MySQL | MySQL Workbench | PostgreSQL | pgAdmin | SQL | PL/pgSQL

## Conclusion

These projects provided practical experience in database design, SQL queries, joins, views, indexes, triggers, stored functions, and database reporting.
